# Animations used in P5.2

- [`animations/p5-coalescing.html`](../../../../animations/p5-coalescing.html): warp lanes → addresses → 32-byte sectors fetched, for contiguous, misaligned and strided access, with a running sector count.
- [`animations/p5-smem-tiling.html`](../../../../animations/p5-smem-tiling.html): a matmul tile loaded into shared memory, the sync, then the bank map for a column read with and without +1 padding. P5.6 reuses it.
