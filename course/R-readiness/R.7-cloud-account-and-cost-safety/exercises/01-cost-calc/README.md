# Exercise 1 — Cost calculator (easy, T0)

Implement four small functions in `cost.py`: `session_cost`, `idle_cost`, `forgotten_cost` and `budget_ok`. They are the formulas from R.7 steps 1, 5 and 4. Every price is an argument. The test uses clearly named made-up values (`EXAMPLE_PRICE`); it never claims a real price. After it passes, use the same formulas with the price you looked up for your own region.

```bash
uv run pytest course/R-readiness/R.7-cloud-account-and-cost-safety/exercises/01-cost-calc
```
